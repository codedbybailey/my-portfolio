## 🌸 About This Project

Welcome to my personal portfolio!

I'm Bailey, a computer science student with a love for creative design, technology, and building things from scratch.

I created this website as a space to showcase my projects, document my learning journey, and experiment with different web development techniques.

Instead of using a traditional portfolio template, I wanted to build something that reflected my personality through playful illustrations, expressive typography, soft colors, and interactive elements.

This portfolio will continue to grow as I learn new skills and complete more projects.

## 🛠 Technologies I Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Website structure |
| CSS3 | Styling, animations, and responsive layouts |
| JavaScript | Website interactions |
| GSAP | Scroll animations and visual effects |
| ScrollTrigger | Scroll-based animation triggers |
| Lenis | Smooth scrolling |
| Git & GitHub | Version control |
| GitHub Pages | Website hosting |

This website is built using vanilla HTML, CSS, and JavaScript without a frontend framework.

## 🎨 Design Inspo

I wanted this portfolio to feel like a creative editorial website rather than a standard developer template.

My design focuses on:

- Bold oversized typography
- Soft pink, coral, cream, and jade green colors
- Organic floral illustrations
- Minimal but expressive graphics
- Smooth transitions between sections
- A balance of playful and professional elements

My goal was to create something memorable while continuing to practice frontend development.
